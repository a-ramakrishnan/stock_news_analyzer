# Stock News Analyzer 0.1.0

The first release for anyone to download. Stock News Analyzer follows a list of Indian stocks for you: every morning it reads what each company filed with NSE and BSE, the news about it, its share price, results, shareholding and earnings calls, and tells you what changed and why it might matter. It runs on your own computer; your stocks, data and API key stay there.

It is not a trading tool and nothing in it is investment advice.

## What it does

- **Today:** each stock's move against the Nifty 50 and its sector, and a morning digest of what was filed and reported overnight
- **Unusual days explained:** the filing or news most likely behind a big move, with how sure it is
- **Results, orders and earnings calls:** revenue and profit each quarter, order wins and order books, what management said and promised, and whether the promises were kept
- **Red flags:** auditors or CFOs leaving, rating cuts, pledges, promoters selling, penalties, late results
- **Shareholding:** promoters, foreign and domestic institutions, mutual funds and retail, each quarter
- **Themes and read-across:** what is rising across your companies, and news at one that may matter to another
- **Ask:** questions in plain English, answered from your own data with the sources listed
- **Gold and silver:** Indian prices split into the global price, the rupee and the rest

Collecting, prices, shareholding and the dashboard need no AI. Triage, explanations, earnings calls, events, themes and Ask use Anthropic's Claude with your own API key, within a monthly budget you set; a watchlist of about 15 stocks costs a few dollars a month after its history is read.

## Install

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Download **Source code (zip)** below and unzip it.
3. Double-click **start.command** (Mac) or **start.bat** (Windows). On a Mac, if it is blocked the first time, right-click it and choose **Open**.
4. The dashboard opens at http://localhost:8501 on a short setup: an API key (optional), your stocks, and their history.

The start script opens Docker Desktop if needed, downloads the app (a few minutes the first time), starts the database, applies any database changes, and starts the dashboard and the scheduler. **stop.command** / **stop.bat** stops it; your data is kept.

The morning jobs run from 07:10 to 08:00 India time, so leave the computer on with Docker Desktop running then. If it was off, the next run catches up.

## Updating

Download the new release, replace the folder's files (keep the `data` folder), and run the start script. It downloads the new version and applies database changes as it starts.

## Known limits

- Tested on a Mac so far; Windows is untested.
- NSE and BSE sometimes refuse requests for a while; jobs retry on their next run.
- History goes back to October 2023.

The [Guide](../../src/stock_news_analyzer/ui/guide.md), also on the dashboard's Guide page, explains each page, a daily routine and what to do when something goes wrong.
